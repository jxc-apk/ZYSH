# 安卓 App 外壳（手机蓝牙打印针式机）

这个目录是一个**极简安卓工程**，只做一件事：

> 把 `https://jxc.0570qz.top` 装进一个 App，并给网页加上「连蓝牙打印机打单」的能力。

**它不打包网页代码**，直接加载线上地址。所以：

- 以后网页改功能、服务器升级，**手机不用重装 App**，打开就是最新版
- 只有"蓝牙打印"这个能力本身需要改的时候，才要重新编 APK

---

## 〇、先确认你这台手机能不能装 APK

**已经确认过：能装。** 你的手机是华为 Mate 80 / 鸿蒙 7.0，
但管家婆物联通（安卓应用）能正常跑并蓝牙打印 —— 说明这台手机有安卓运行环境
（小米/华为 NEXT 系列常见是装了「卓易通」这类兼容层）。**所以这个 APK 走得通。**

> 如果以后换了纯鸿蒙 NEXT（没有兼容环境）的手机，这个 APK 装不上。
> 那种情况要改成**鸿蒙原生版**：鸿蒙官方有
> [`@ohos.bluetooth.socket`（Bluetooth Socket，带 SPP 读写）](https://developer.huawei.com/consumer/en/doc/harmonyos-references-V5/js-apis-bluetooth-socket-V5#socketoffsppread)，
> 能做，但要装 DevEco Studio 重新写一个壳。
> **好消息是排版引擎（`web/src/utils/escprint.js`）和网页端都不用改，只换壳。**

## 一、为什么要装 App，网页直接打不行吗

不行，这是浏览器的硬限制，不是没做：

| | 网页（PWA） | 这个 App |
|---|---|---|
| 能连的蓝牙 | **只能低功耗蓝牙（BLE）** | 经典蓝牙 + 低功耗都能 |
| 你的得实 DS-1900 | ❌ 连不上 | ✅ 能连 |
| 管家婆物联通能打的原因 | —— | 它也是原生 App |

得实 DS-1900 的蓝牙是**选配的串口模块**（官方参数：接口 USB/并口，选件 串口/WIFI/蓝牙），
走的是**蓝牙经典 SPP**。浏览器规范里没有连 SPP 的能力（Web Bluetooth 只支持 BLE），
所以必须由原生这一层来发数据。

## 二、怎么编出 APK（手把手）

### 第 1 步：电脑上装 Android Studio

下载地址：https://developer.android.com/studio

安装时一路下一步即可。第一次启动会自己下载 Android SDK（约 1-2 GB，耐心等）。

> 如果你的电脑配置低或不想装，可以跳到最后的「方案 B：不用装 Android Studio」。

### 第 2 步：打开工程

1. Android Studio → **Open**（不是 New Project）
2. 选中这个 `android` 文件夹（就是本文件所在的目录）
3. 等右下角进度条跑完（第一次要下载依赖，约 3-10 分钟）

### 第 3 步：编出 APK

菜单 **Build → Build Bundle(s) / APK(s) → Build APK(s)**

等一会儿，右下角会弹出提示，点 **locate** 就能打开 APK 所在的文件夹：

```
android/app/build/outputs/apk/debug/app-debug.apk
```

这个 `app-debug.apk` 就可以直接装到手机上了。

> **debug 版和 release 版的区别**：debug 版能直接用（我们没写任何需要签名的功能），
> 装的时候手机会提示"未知来源"，允许即可。如果以后要正式分发再编 release 版。

### 第 4 步：装到手机

把 `app-debug.apk` 传到手机（微信文件传输助手 / 数据线都行），
在手机上点它 → 允许「安装未知应用」→ 装好。

打开 App 就是你的进销存系统，**登录一次就记住了**。

## 三、手机打印怎么用（在 App 里）

### 第一次用（配置打印机，只需一次）

1. **先在手机系统里配对打印机**（App 不负责配对）：
   设置 → 蓝牙 → 打开 → 搜索到 `DS-1900`（或类似名字）→ 点击配对
   （打印机要开机，有的机型要先按一下打印机上的蓝牙键）
2. 打开 App → 进任意一张**已确认**的单据 → 右上角 **⋮ 更多操作**
3. 点「**蓝牙打印**」→ 如果还没选过打印机，会列出已配对的设备
4. 选你的 `DS-1900` → 会**测试连接一次**并把结果告诉你
5. 连接成功后自动开始打印

以后每次打印**不用再选**，直接点就打。

## 四、打不出来怎么办（按顺序排查）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 提示"没有蓝牙权限" | 安卓 12+ 需要授权 | App 里点允许；或系统设置 → 应用 → 进销存 → 权限 → 附近的设备 → 允许 |
| 提示"蓝牙没打开" | 手机蓝牙关了 | 系统里打开蓝牙 |
| 列表里没有你的打印机 | 没在系统里配对 | 先去系统蓝牙里配对（本 App 不扫描新设备，只用已配对的） |
| 点打印提示"连接打印机失败（三种方式都试过了）" | 打印机被别的 App 占着，或离太远 | ①关掉管家婆/其它打印 App ②手机靠近打印机（1 米内）③打印机重启一下 |
| 出纸了但是**乱码** | 打印机不支持 GB18030 中文模式 | 告诉我，我改成先发中文模式指令或换编码 |
| 出纸了但是**排版歪** | 打印机列宽不是 82 列 | 告诉我你的实际列数（一般 82 或 76），我调列宽 |
| 打一半断了 | 蓝牙信号弱 | 靠近一点；已经加了"打完等 400ms 再断开"，减少截断 |

**卡在哪一步，把提示原文告诉我**，我按现象改。

## 六、打不开 / 卡住 / 报错怎么办（国内最常见）

### 症状 1：打开工程后一直转圈，或报 `Could not resolve...`

**原因**：Gradle 连不上 `google()` / `mavenCentral()`（国内经常不通）。

**已经处理好了**：`settings.gradle` 里把**阿里云镜像放在了最前面**，国外源只作兜底。
如果你是升级前的旧包，替换成新的 `settings.gradle` 即可。

### 症状 2：卡在 `Downloading gradle-8.x-bin.zip`

**原因**：Gradle 发行版从 `services.gradle.org` 下载，国内很慢甚至下不动。

**已经处理好了**：加了 `gradle/wrapper/gradle-wrapper.properties`，
把发行版地址指到**腾讯云镜像**（`mirrors.cloud.tencent.com/gradle/`）。

### 症状 3：Android Studio 本身打不开（点了没反应 / 闪退）

这不是工程的问题，是电脑环境的问题，按顺序查：

| 检查项 | 要求 | 怎么查 |
|---|---|---|
| 内存 | **至少 8 GB**，建议 16 GB | 任务管理器 → 性能 |
| 磁盘剩余空间 | **至少 15 GB** | 此电脑 |
| 是否装了 JDK 冲突 | Android Studio 自带 JDK，**不要**另外设 `JAVA_HOME` 指到老 JDK | 系统环境变量 |
| 杀毒软件拦截 | 360/火绒有时拦 IDE | 临时关掉试试 |
| 安装路径有中文 | 有的版本会出问题 | 装到 `D:\AndroidStudio` 这种纯英文路径 |

**如果电脑配置不够（内存 8G 以下 / 机械硬盘）**，Android Studio 会非常难用。
这种情况直接用**方案 B（云编译）**，不装 IDE —— 见下面第七节。

### 症状 4：装上了但找不到 Java

Android Studio 新版自带 JDK（叫 JBR），不需要你单独装 Java。
如果报 JDK 相关错误，检查：`File → Settings → Build → Build Tools → Gradle → Gradle JDK`
选 `jbr-17`（列表里自带的那一项）。

## 七、方案 B：不用装 Android Studio（云编译）—— 电脑配置不够就用这个

**工程里已经带好了工作流文件**（`.github/workflows/build.yml`），你不用自己写任何东西。

### 手把手（全程点鼠标）

1. **注册 GitHub 账号**（免费，2 分钟）：https://github.com/signup
2. 右上角 **+** → **New repository**
   - Repository name 填 `jxc-apk`（随便填）
   - 选 **Public**
   - 点 **Create repository**
3. 在新仓库页面点 **uploading an existing file**（蓝色小字链接）
4. **把 `android` 文件夹里的所有内容拖进浏览器窗口**
   - ⚠️ 关键：拖**里面的内容**（`settings.gradle`、`app` 文件夹、`.github` 文件夹…），
     让 `settings.gradle` 出现在仓库根目录，**不要**把 `android` 文件夹本身拖进去
   - ⚠️ `.github` 是隐藏文件夹：文件管理器「查看」里勾上「隐藏的项目」才看得到
   - 拖完点绿色 **Commit changes**
5. 点仓库上方 **Actions** → 左边选 **build-apk** → 右边 **Run workflow** → 绿色按钮
6. 等 **3-5 分钟**（第一次慢些），刷新页面，点进那次运行记录
7. 页面**最下方 Artifacts** 里有 **app-debug** → 点它下载
8. 下下来是个 zip，解压得到 **app-debug.apk** → 发到手机安装

> 以后要重新编，进仓库点一下 **Run workflow** 就行，不用再上传。

### 云端编译和本地编译一样吗

一样。同一份代码、同一套 Gradle 配置，编出来功能完全相同。
唯一区别是签名：云端编的是 **debug 签名**（能直接装，够用），
和你本地编的 debug 版同一性质。

### 还有一条最快的路

**把 `jxc-android.zip` 发给懂技术的朋友或电脑店**，让他用 Android Studio 打开编一次，
5 分钟的事（这是最省你时间的办法）。他需要的就是 README 里第二节那四步。

### 给网页暴露的接口（`window.JxcPrinter`）

网页里判断 `window.JxcPrinter` 存在就显示「蓝牙打印」按钮。所有方法都返回字符串，
**空串表示成功**，否则是给用户看的错误说明（这样网页端不用做异常处理）：

| 方法 | 说明 |
|---|---|
| `isAvailable()` | 返回 true，网页用它判断"我在 App 里" |
| `platform()` | 例如 `android-33` |
| `listPaired()` | 已配对设备，JSON 数组 `[{name, mac}]` |
| `selectPrinter(mac, name)` | 选定并记住打印机 |
| `savedPrinter()` | 返回 `mac\|name`，没选过返回空串 |
| `isBluetoothOn()` | `"1"` / `"0"` |
| `hasPermission()` | `"1"` / `"0"` |
| `requestPermission()` | 弹系统授权框 |
| `print(text, encoding)` | 打印；针式机传 `GB18030` |
| `testConnect()` | 只连不打，用来测通路 |
| `toast(msg)` | 原生弹提示 |

### 两个关键实现细节（改代码时别踩）

1. **连接要试三种方式**
   同一个 SPP UUID，有的打印机只认"安全连接"，有的只认"非安全连接"，
   老机器还只认固定 channel 1。只试一种，用户就只看到"连接失败"。
   `BluetoothPrinter.connect()` 依次试三种，成功了记住用的是哪种，下次优先用。

2. **socket 操作必须在子线程**
   `print()` 是 JS 线程调进来的，直接在里头做 socket 操作会抛
   `NetworkOnMainThreadException` 把 App 搞崩。所以里面另起线程并等结果。

### 中文编码在哪做

JS 的 `TextEncoder` 只支持 UTF-8，编不出 GB18030，所以**不在前端做**：
原生这边用 `Charset.forName("GB18030")` 编码（安卓系统自带，零依赖）。
网页只负责把排版好的字符串传过来。

排版逻辑在 `web/src/utils/escprint.js`（纯函数，有 50 项测试：
中文按 2 列算、每行不超过 82 列、数字右对齐等）。
